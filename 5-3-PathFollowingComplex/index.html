Trois points à distinguer

F est devant le véhicule, à une distance fixe. H est le candidat retenu sur le circuit. T avance dans la direction du segment. Seek vise T uniquement si FH dépasse strictement le rayon.

Le calcul historique projette sur une droite, puis remplace une projection extérieure par B et utilise la direction suivante. Ce traitement est conservé : ce n'est pas un bornage classique au segment.

Expérimenter : mettez en pause, choisissez un agent, faites un pas. Augmentez l'anticipation puis observez le segment choisi. Au croisement, les distances égales favorisent le premier segment.

T : serpent au pointeur · d : détails · s : véhicule rapide · w : Wander. Glisser sur le canvas ajoute des véhicules ; en édition, glisser un sommet déplace le chemin. Cliquer un agent le sélectionne.

Masquer les détails ne désactive aucun comportement. La séparation peut agir même quand la correction de suivi est inactive. Le corps du serpent utilise Arrive ; Wander concerne les véhicules ordinaires.

Décision physique

Les réglages agent concernent le véhicule ou la tête sélectionnée. Les réglages « tous serpents » s'appliquent au groupe et aux créations suivantes. Reset rétablit les agents du scénario ; le rayon et les réglages du groupe sont conservés.
