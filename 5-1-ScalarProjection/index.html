04 / LIRE LES MATHÉMATIQUES

Du produit scalaire au point projeté

a = P − O · b = B − Ou = b / ‖b‖s = a · up = s u · H = O + pr = P − Ht = (a · b) / (b · b)

La droite est infinie : s peut être négatif et t peut dépasser 1. Pour le segment, tborné = min(1, max(0, t)) et Q = O + tbornéb. PH est perpendiculaire à la droite ; PQ n’est pas nécessairement perpendiculaire au segment. Si O = B, la droite est indéfinie mais le segment réduit à O possède encore un point le plus proche.
